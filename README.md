# Smart Home Automation System

## Project Overview
The Smart Home Automation System is a web-based application developed as an Innovation and Design Project . It provides a simple and user-friendly interface to control and monitor smart home devices through a web browser.

## Features
- Web-based smart home control
- User-friendly interface
- Device monitoring and control
- Responsive design
- Secure login and authentication
